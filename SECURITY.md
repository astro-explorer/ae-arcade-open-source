# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through **GitHub private vulnerability reporting**:

**[https://github.com/astro-explorer/ae-arcade-open-source/security/advisories/new](https://github.com/astro-explorer/ae-arcade-open-source/security/advisories/new)**

**Do not** file a public GitHub issue, pull request, or Discord message describing the vulnerability. Public disclosure before a fix is in place puts forks and downstream users at risk.

## Scope

This policy covers the **open-source reference repository** at `astro-explorer/ae-arcade-open-source` only.

The production AE Arcade deployment runs from a separate private repository and is **out of scope** for reports filed here. If you've found a vulnerability that affects the live arcade specifically (e.g. a deployment-only misconfiguration), please reach out through the channels listed on the production site rather than this repo.

## Response

This is a community project maintained on a best-effort basis. There is **no formal SLA** for triage or fix times. We will:

- Acknowledge your report when we see it.
- Investigate and confirm the issue.
- Coordinate a fix and disclosure timeline with you.

## Fix policy

We follow **coordinated disclosure**. Once a fix is ready, we'll publish a GitHub Security Advisory describing the issue and its resolution. Reporters are credited by name (or handle) in the advisory if they want to be — let us know your preference when reporting.
